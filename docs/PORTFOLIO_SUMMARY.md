# 案件提案用の作品紹介

## ApprovalFlow — C# / ASP.NET Core 稟議管理

自主制作として、申請者・承認者の権限を分けた稟議管理Webアプリを設計・構築しました。下書き、申請、差戻し、修正・再申請、承認の流れと操作履歴を管理します。

技術: C#、ASP.NET Core 10、Entity Framework Core、SQL Server、JavaScript、Docker、xUnit。

説明できる設計: 所有者単位のアクセス制御、CSRF対策、バージョンを条件にした競合制御、更新と履歴のトランザクション、DB制約、検索・ページング、SQL Serverを使った自動試験。

業務経歴・実務年数とは別の自主制作作品です。C#案件で必要な実務経験、顧客折衝や本番運用実績を示すものではありません。公開URLはGitHubへ公開した後に記載してください。
